# Пример результата

`example.docx` — реальный результат работы сервиса (GigaAM v3 E2E RNNT, GPU), сгенерированный из синтетической русской речи (Windows/Edge TTS) длительностью 16 секунд с включёнными таймкодами.

Файл не является частью Docker-образа (`.dockerignore` исключает `*.docx`) и не содержит персональных данных. Открывается в Microsoft Word, LibreOffice и python-docx.

Содержимое:

- заголовок «Транскрибация: Итоговая проверка.wav»;
- таблица метаданных (файл, длительность, дата, модель, язык, время обработки, RTF, версия образа);
- текст с префиксами `[ЧЧ:ММ:СС]`;
- футер «Страница X из Y» с полями `PAGE`/`NUMPAGES`.
